# 🎮 Rock Paper Scissors

A simple **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.

🌐 [**Live Demo**](YOUR-LIVE-LINK)

[Rock Paper Scissors Screenshot](Screenshot.png)

## ✨ Features

- 🪨 Player can choose Rock
- 📄 Player can choose Paper
- ✂️ Player can choose Scissors
- 🤖 Computer makes a random choice
- 🏆 Displays the game result
- 🔢 Displays the score
- 🔄 Allows playing multiple rounds

## 🛠️ Technologies Used

- **HTML** – Structure
- **CSS** – Styling and layout
- **JavaScript** – Game logic, DOM manipulation, and event handling

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
